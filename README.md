# Figma Clone (Nuxt 4)

Учебный проект — аналог стартовой страницы [figma.com](https://www.figma.com), выполненный в рамках изучения фреймворка Vue.js и Nuxt 4.

**🌐 [Посмотреть живое демо на Vercel](https://ВАША-ССЫЛКА-НА-VERCEL.vercel.app)** *(замените ссылку после деплоя)*

## 🚀 Стек технологий

*   **Фреймворк:** [Nuxt 4](https://nuxt.com/) (Vue 3, Composition API)
*   **UI-библиотека:** [Vuetify 3](https://vuetifyjs.com/) (компоненты, сетка, иконки Material Design)
*   **Стилизация:** SCSS (встроенная поддержка в Nuxt)
*   **Линтинг:** ESLint (модуль `@nuxt/eslint`)

## ✨ Реализованный функционал

*   **Адаптивная верстка:** Полностью сверстан длинный лендинг по макету Figma (шапка, главный экран, блоки с фичами, галерея, цитаты, футер).
*   **Многостраничность / Модальные окна:** Реализовано модальное окно регистрации, которое открывается поверх главной страницы (как на оригинальном сайте).
*   **Анимации:** 
    *   Плавное появление элементов при загрузке главного экрана.
    *   Микро-интерактив: выезжающая стрелочка при наведении на кнопки "Get started".
*   **Кастомные компоненты:** Имитация сложных интерфейсов (окно браузера, коллажи, градиенты) с помощью CSS и Vuetify.

## 🛠 Установка и запуск

Убедитесь, что у вас установлена **Node.js** (версия 22 или выше) и пакетный менеджер **Yarn** (или npm).

1.  Клонируйте репозиторий:
    ```bash
    git clone <ссылка-на-ваш-репозиторий>
    cd <название-папки-проекта>
    ```
2. Установите зависимости:

```bash
yarn install
```
3. Запустите сервер разработки:

```bash
yarn dev
```
4. Откройте http://localhost:3000 в браузере.

📦 Сборка для продакшена
Для создания оптимизированной версии сайта выполните:

```bash
yarn build
```
Предпросмотр продакшен-сборки:

```bash
yarn preview
```
